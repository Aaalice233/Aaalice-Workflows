# Aaalice_Workflow v0.3 更新日志

## ✨ 本次更新

- 修复 **Qwen VAE 导致多图批量生成时只有第一张生效**的问题
- **潜空间放大与像素空间放大的默认采样参数调整**：两处采样器由 euler 改为 euler_ancestral；像素空间放大的调度器由 beta 改为 normal
- **像素空间放大默认放大模型更换**：由 4x_foolhardy_Remacri 换成 4x-UltraSharp
- **默认示例图统一更新**：文生图各区（底图、潜空间放大、像素空间放大、SeedVR2 放大及各对比预览）与图像反推的占位示例图统一更换为 Aaalice_example.jpg
- 默认正面提示词与多处节点说明文本更新
- 侧边栏新增**参数调整档案**：把常用的控件数值存成可复用的规则，一键套用到当前工作流
- 画廊新增**全局输出过滤标签**：复制的提示词自动剔除不想要的标签，帖子展示不受影响
- 新增**条件保存图像节点**：开关关闭时不写盘、图像原样透传，调试时不再刷出一堆废图

## 🧩 ComfyUI 内核

## 🎨 ComfyUI-Aaalice-Nodes v0.9 → v0.14.2

### 侧边栏 / 参数调整

- 新增**参数调整档案**：常用控件数值保存成规则随时一键套用，支持按卡片管理，失效规则自动进入复核清单
- 调整档案可**限定只对某些页面生效**，多绑定的卡片只出现一次候选，标题实时跟随卡片
- 修复连续添加规则时搜索框和滚动位置被重置
- 修复侧边栏选中图片后偶尔显示"图片丢失"占位符

### 画廊

- 新增**全局输出过滤标签**，复制的提示词自动剔除指定标签
- 标签输入全面接入 Autocomplete 补全，候选面板打开时不再误提交
- 搜索零结果时显示明确的空态提示，不再只有一句"已经到底了"
- Danbooru 受限内容在低等级账号下会给出明确提示，不再无限空白加载
- 修复反推按钮偶尔消失、补全面板关闭后搜索不触发

### 其他

- 新增**条件保存图像节点**
- 同时装了旧版 Danbooru-Gallery 时会弹窗提醒卸载
- 修复 Nodes 2.0 下分辨率画板无法拖拽
- 侧边栏和各类弹窗里的复制/粘贴不会再误触发画布粘贴节点

## 🛠️ ComfyUI-Aaalice-Workflow-Hub（安装工具）

自上版工作流发布以来，Workflow Hub 更新到了 **v1.2.0**：

- **发布更新日志支持导入 Markdown 文件**：发布和编辑更新日志时可一键导入本地 .md 文件
- **更新提醒改版**：入口数字角标改为简洁红点；悬停红点直接看到具体是哪些工作流更新到哪个版本；不想更新的版本可以右键"忽略本次更新"，下次发布新版本会重新提醒
- **更新通知去重**：新增提醒上限，不再反复弹同一个更新提示
- **自动继承 Windows 系统代理**：git / pip 下载自动走系统代理，无需额外配置
- **适配秋叶启动器的国内镜像**：插件和 Python 包下载走国内镜像源，速度快很多
- 修复未登录时订阅刷新失败、残留旧清单的问题
- 修复多用户 ComfyUI 下接口报 Unknown user 的问题
- 依赖弹窗里的插件可以直接跳转来源页面（GitHub 仓库 / Registry 节点页）

> 建议通过 ComfyUI-Manager 或启动器把 Workflow Hub 更新到最新版，获得上述改进。
