# Aaalice Workflow v0.4 更新日志

## ✨ 本次更新

### 🖼️ 图像对比与默认流程

- 补齐底图、双采样底图、潜空间放大、像素空间放大和 SeedVR2 放大的图像对比预览联动；开启对应处理组时，会自动联动显示相应对比结果。
- 默认放大方案由像素空间放大切换为 **SeedVR2 放大**，开箱即用的流程更偏向稳定清晰化。
- 图像对比依赖 **Nodes 2.0** 显示，工作流内已补充开启位置和使用提醒。

### ⚙️ 默认参数调整

- **潜空间放大**：默认放大倍数由 `1.5` 调整为 `1.35`，采样器由 `euler_ancestral` 调整为 `euler`，继续搭配 `simple` 调度器。
- **SeedVR2 放大**：默认放大倍数由 `2` 调整为 `1.5`，减少过度放大带来的耗时和画面波动。
- **默认-Krea2-Turbo-Int8** 与 **默认-Anima** 两套侧边栏预设已同步以上参数。

### 📖 使用说明

- 补充潜空间放大的倍数、降噪和推荐采样组合说明。
- 更新配套插件能力介绍，补充组跳转轮盘、Booru 画廊和 Lora Manager 联动说明。

## 🎨 ComfyUI-Aaalice-Nodes v0.14.2 → v0.14.4

### 🖼️ Booru 画廊

- 重做悬浮大图预览，集中展示分辨率、评分、收藏和标签数量等信息。
- 标签支持分类展示与汉化，查看参考图内容更直观。
- 进一步优化预览布局和标签数量显示。

### 🎛️ 侧边栏

- 组开关预设现在只保存组的启用状态，不再夹带无关参数。
- 修复输出图像引用保存不完整的问题，重新加载工作流后不再丢失。
- 修复切换子图后图像参数可能丢失的问题。
- 优化规则设置弹窗的宽度和阅读体验。

### 🧰 图像处理

- 修复 SeedVR2 批量处理多张图片时可能出现内容串图的问题。

## 🛠️ ComfyUI-Aaalice-Workflow-Hub v1.2.2（安装工具）

- 加载工作流时会保留原始文件名，后续查找和管理更直观。
- 兼容 comfyui-xiao 自带的 Git 环境，安装与更新更稳定。
- 调整工作流中心面板高度和详情页滚动布局，长内容更容易浏览。
- 修复更新提示与 ComfyUI 自带提示重叠的问题。
