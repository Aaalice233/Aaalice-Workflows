# Aaalice Workflow v0.6 更新日志

## ✨ 本次更新

### 🎨 默认采样与放大方案调整

- **底图**分组的默认采样器由 `euler` 改为 `linear/euler`，调度器由 `beta` 改为 `beta57`。
- **底图-双采样器**分组同步切换为 `linear/euler` + `beta57`（前后半段一致）。
- **潜空间放大**分组的调度器由 `simple` 改为 `beta57`，采样器同样改为 `linear/euler`。
- **像素空间放大**分组的默认采样器由 `euler_ancestral` 改为 `linear/euler`，调度器由 `normal` 改为 `beta57`。
- 文生图默认出图链路改为走**潜空间放大**（现已默认启用），**SeedVR2 放大**默认关闭；两组对比区域也同步切换。想用 SeedVR2 的话在对应分组手动启用即可。

> 新采样器与调度器由新增的 **RES4LYF** 插件提供，更新插件后记得安装。

### 🤖 OC 角色替换

- **提示词后处理**分组新增「📚 提示词选择器（OC）」节点，配合提示词优化可以把画面角色一键替换成你的 OC。

### 🧭 轮盘导航

- 跳转目录重新整理，由 8 个入口扩充到 **11 个**：新增「提示词」「提示词后处理」「【📦可选】图像反推」三个跳转点。
- 排序按使用动线重排：组控制 → 基础设置 → 提示词 → 提示词后处理 → 画廊 / 图像反推 → 各预览与对比区域，并按各分组实际大小调整了跳转后的缩放和位置。

### 🗂️ 侧边栏整理

- 新增「📋提示词后处理」页面：提示词优化、OC 替换的设置集中放在这里。
- 「🎨底图参数」页面重新精简：采样参数、图像保存、消息通知、底图确认分组归类更清晰，步数 / cfg / 降噪等滑条补上了合理的数值范围。
- 部分页面名称微调（如「📋提示词前后缀」）。

### 📝 其他

- 默认底模更换为 `anima-turbo-v1.0-int8convrot.safetensors`（须知里的下载链接已同步更新，更省显存）。
- 说明文本补充了潜空间放大的使用建议：降噪不低于 0.4，推荐 `linear/euler` + `beta57`。
- 默认示例提示词更换为 evil Neuro-sama 主题。
