# Aaalice_Workflow v0.9 更新日志

## ✨ 本次更新

### 🖼️ 图像生成元数据

- 我提交给 **ComfyUI-Lora-Manager** 的元数据修复 PR 已正式合并
- 正、负提示词经过增强、清空或开关选择后，生成图片仍会正确记录实际使用的提示词，不再缺失内容或误记未选中的分支
- 至此，本工作流生成图片所需的提示词、模型、LoRA 和采样参数等元数据已经可以完整保存，后续查看与复现参数更可靠

### 📦 侧边栏画廊

- 侧边栏新增独立的**画廊**页面，可以直接浏览、搜索、筛选、翻页和选择参考图
- 画廊与画布节点实时同步；在任意一处进行操作，另一处都会保持一致
- 侧边栏预设现在可以保存并恢复画廊的来源、搜索、筛选、分页、随机模式和已选图片等完整状态

## 🎨 ComfyUI-Aaalice-Nodes v0.15.1 → v0.15.2

### 🖼️ 画廊

- 画廊现在可以完整加入侧边栏，并与画布节点共享搜索、筛选、分页、随机模式、选择结果和设置
- 侧边栏预设可以完整保存和恢复画廊状态
- 在侧边栏使用画廊时，画布上的同一画廊会暂停显示，避免两处同时加载大量图片；离开后自动恢复
- 搜索输入在提交前会保留草稿，不再被状态同步意外覆盖

### 🎛️ 侧边栏

- 调整档案界面按参数来源分组，并加入搜索与直接编辑；规则会自动保存，只有点击套用后才修改当前侧边栏
- 保存预设时不再让整个侧边栏重新加载，画廊不会因此闪烁或重复请求
- 导入预设时始终创建新的命名副本，不会覆盖已有预设
