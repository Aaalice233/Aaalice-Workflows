## ✨ 本次更新

> **⚠️ 重要：本版强烈建议关闭 Nodes 2.0**
>
> 当前 Nodes 2.0 存在明显性能问题，本工作流已不再依赖它的图像对比功能。请点击左上角 ComfyUI Logo，关闭 Nodes 2.0 后使用 **Classic 模式**。

### 🎨 双采样底图升级

- 修复双采样底图的采样连接方式，确保前后两段按正确顺序衔接。
- 两段采样之间新增 **SesquiLSR 潜空间放大**：第一段到达「采样器切换步数」后先放大潜空间，再交给第二套模型、提示词和采样参数继续生成。
- **「🎨双采样底图参数」**侧边栏新增「潜空间放大倍数」与「潜空间缩放方法」，默认使用 **1.5 倍 + Wan 2.1**，可以直接按需要调整。
- 更新默认采样参数：普通底图改为 **Euler + beta**，双采样底图第二阶段改为 **Euler + simple**。
- 工作流内说明同步补充双采样放大、倍率叠加和显存占用提醒，减少重复放大或误开多个阶段。
- 重新整理组导航顺序，将「提示词后处理」提前，并让底图预览、放大与细化对比入口按工作流顺序排列。

### 🧩 插件兼容与修复

- **ComfyUI-Lora-Manager** 现在可以把本机仍然存在、但 Civitai 端已经删除或不可用的 LoRA 正常保存进配方。
- 修复 **ComfyUI-Aaalice-Nodes** 导入词库时可能因预览大图超限而失败的问题，过大的图片会自动压缩后再导入。
- **comfyui_queue_sidebar** 已正确适配简体中文；简体中文与繁体中文现在会分别加载对应语言。
- 优化 Booru 画廊双标签随机浏览，大型或稀疏结果集不再容易少图、断流；同时修复 Danbooru 收藏夹随机模式的排序冲突。
