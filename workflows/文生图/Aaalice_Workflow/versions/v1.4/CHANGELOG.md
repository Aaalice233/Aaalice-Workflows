## ✨ Aaalice Workflow v1.4 更新

> **⚠️ 重要：本版强烈建议关闭 Nodes 2.0**
>
> 当前 Nodes 2.0 存在明显性能问题，本工作流已不再依赖它的图像对比功能。请点击左上角 ComfyUI Logo，关闭 Nodes 2.0 后使用 **Classic 模式**。

### 🎨 双采样底图修正

- 调整双采样流程：第一个采样器现在会完整生成底图，再通过 **SesquiLSR** 放大潜空间，最后由第二个采样器从「采样器切换步数」继续补充细节。
- 例如总步数为 8、切换步数为 4 时，第一段运行 8 步，第二段再运行第 4～8 步，实际共采样 12 步。
- 潜空间放大倍数默认由 **1.5** 调整为 **1.35**，第二段调度器由 **simple** 调整为 **sgm_uniform**，相关默认预设已同步更新。
- 各默认预设中的第二套 LoRA 堆改为默认关闭，需要为第二段使用另一套 LoRA 时再手动开启。

### 🌸 新增 Anima V1 Turbo 预设

- 侧边栏新增 **「默认-Anima-V1-Turbo-Int8」** 预设，已配置对应底模、文本编码器和推荐采样参数，可直接切换使用。
- 工作流内的模型下载说明同步补充 **Anima-V1-Turbo-Int8** 所需文件与放置路径。

### 🔗 LoRA 兼容与触发词

- 修复第二套 LoRA 触发词的传递：普通底图、双采样底图、潜空间放大、脸部细化和局部重绘现在都能正确跟随所选 LoRA 堆，不再误用第一套触发词。
- **ComfyUI-Lora-Manager 已合并我的修复 PR**：Civitai（C 站）LoRA 与非 C 站 LoRA 混用时，解析配方也能完整识别其中的所有 LoRA。

## 🎨 ComfyUI-Aaalice-Nodes v0.18.2 → v0.18.3

### 🧰 侧边栏与预设

- 侧边栏预设现在支持拖拽排序，也可以使用 **Alt + 方向键** 调整顺序；新顺序会随工作流保存。
- 调整档案现在可以直接复制，档案中的规则也会一并保留。
- 强化预设排序手柄的悬停、按压、拖拽和键盘焦点反馈，操作位置更容易辨认。

### 🖼️ Booru 画廊

- 切换视图、改变列数或画廊重新显示后，会尽量回到原先浏览的卡片位置和页数，不再轻易跳回顶部。
- 优化画廊卡片操作区，并移除卡片中重复的图像反推入口；仍可通过工作流原有的图像反推流程处理已选图片。
- 修复快速滚动和切换卡片时，加载中、禁用或错误状态可能串到其他卡片的问题。
- 改善图片加载与回收；在部分系统中加载 HTTPS 图片更稳定，证书异常时也会给出更清楚的原因。

### ⚡ 图像处理与性能

- 优化大图缩略图列表的滚动性能，图片较多时浏览更顺畅。
- 修复透明图层可能被误判为纯黑图像的问题。
