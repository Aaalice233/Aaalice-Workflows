## 语言与依据

- 面向用户的内容优先使用简体中文；代码、命令、路径、配置项、API 和专有名词保持原样。
- 优先依据代码、日志、配置、项目结构和官方文档判断，不凭印象猜测。
- 信息可能过时、有歧义或影响较大时，先检索验证。

## 工作原则

- 修改前确认真实目录结构、目标文件、调用关系和当前内容。
- 仅修改任务直接涉及的内容，保持现有风格、结构、命名和模块边界。
- 优先复用已有模块与约定，不为单次需求新增通用抽象。
- 工作区已有改动默认属于用户，不回滚、覆盖、清理或格式化无关内容。
- 不确定事项优先通过只读检查确认；不同选择会显著影响结果时再提问。
- 修改后运行与风险匹配的最小范围验证，并如实报告结果。

## PowerShell 与路径

- 默认使用 PowerShell 7+（`pwsh`）；除非明确要求，不使用 `cmd.exe` 或旧版 `powershell.exe`。
- 多行 PowerShell 命令以此开头：

  ```powershell
  $ErrorActionPreference = 'Stop'
  ```

- 文件读写显式指定 `-Encoding UTF8`，但不得用它重写编码或换行敏感文件。
- 数据处理优先使用 PowerShell 对象管道，不混用其他 Shell 语法。
- 路径优先使用 `/`，例如 `C:/Users/...`；仅在程序明确要求时使用 `\`。
- 含空格路径必须加引号；路径不确定时先检查。
- 临时文件优先放在项目内明确目录。
